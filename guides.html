Published voter guides

Publisher guides and lists across political viewpoints, including conservative, labor, environmental, business and reproductive-health organizations. Read each publisher’s priorities and sourcing before using its guide.

Questionnaires and ratings are not automatically endorsements. A party candidate listing is separate from nomination. The main guide counts only the positions described in each source card; a link here does not mean every entry has been imported. See coverage and unresolved gaps.

Have you found gaps or errors in the data? Know an endorsing entity that should be added? Please create an issue on Github.
